# RNode 25.1.32.0

**Released:** 2026-11-13 · **Build:** 123 · **OpenWrt** 25.12.6 · **Bitcoin Core** 32.1

The first public release on OpenWrt 25.12. It brings in everything from
25.0.32.0 (a factory-only release): OpenWrt 25.12, Bitcoin Core 32.1 and
Core as the only node software. It also fixes the bugs found while writing
the user guide, and every page is now translated into seven languages.

---

## Which file do I need?

| You have | Do this | File |
|---|---|---|
| A router on **25.0.32.0** | **Settings → Appliance upgrade**, *Keep settings* ([User Guide §9](../USER_GUIDE.md#9-updating-the-firmware)) | `bpi-r4-phase2-25.1.32.0-squashfs-sysupgrade.itb` |
| A router on **24.10.8.29.5.119** or older | A **fresh install**, not Settings → Appliance upgrade (see below) | `bpi-r4-phase2-25.1.32.0-sdcard.img.gz` (SD card) |
| A new board | A fresh install from the SD card ([FACTORY_EMMC_INSTALL.md](../FACTORY_EMMC_INSTALL.md)) | `bpi-r4-phase2-25.1.32.0-sdcard.img.gz` |

### Updating from 25.0.32.0

- Takes about 5 minutes and ends on Node Status. Wi-Fi, passwords, network,
  the secure connection and the blockchain are kept.
- **Your node settings go back to the defaults once.** 25.0.32.0 did not keep
  Settings → Bitcoin node configuration across an update. Write down any
  values you changed and set them again afterwards. From 25.1.32.0 on, they
  are kept.

### Coming from 24.10.8.29.5.119 (OpenWrt 24.10)

The move to OpenWrt 25.12 also replaces the router's boot loader, which an
in-place update cannot do. Install 25.1.32.0 fresh from the SD card or over
the serial console ([NOTICE.md](../../NOTICE.md#installing-your-own-build)).

- **The blockchain on the M.2 drive is kept.** The node starts on the same
  chain data, with no re-download.
- Router settings are not kept: Setup runs again.
- A router that ran **Bitcoin Knots** starts **Bitcoin Core 32.1** on the same
  chain data. Knots is no longer offered.

## What's new since 24.10.8.29.5.119

### Router and node

- **OpenWrt 25.12.6.** OpenWrt 24.10 lost security support in September 2026.
- **Bitcoin Core 32.1** (was 29.5), installed only after checking Bitcoin
  Core's own release signatures. It fixes CVE-2025-46598. The previous version
  stays on the drive so **Node software → Rollback** still works.
  `maxconnections=125` and `natpmp=0` stay as before.
- **Bitcoin Knots is no longer offered.** A router that ran Knots switches to
  Core on the same chain data. An old Knots install on the drive is left
  untouched.
- Container base updated to Debian 12.15.
- Updates are accepted only when signed with a maintainer's firmware key
  (`2e51b93dd6058ffb`). The standby key `833eb2b299741478` is retired and no
  longer trusted.
- After a factory reset, the first-use page that sends a new computer to
  Setup is ready as soon as the router is.

### Fixed in 25.1.32.0

- **Quick Start keeps an ISP (PPPoE) login** typed in its pop-up. Before, it
  always switched the internet back to DHCP. It also drops values left over
  from an abandoned Guided Setup.
- **Node settings are kept across firmware updates** (Settings → Bitcoin node
  configuration). Settings that only RNode controls always come from the new
  firmware, and defaults you never changed follow the new firmware.
- **Timezone:** a browser timezone missing from Setup's list now selects a
  listed one with the same offset and says so. Before, it always chose
  Australia/Sydney and its Wi-Fi country.
- Guided Setup's Wi-Fi step says correctly that the change applies when Setup
  finishes.
- The status light blinks very fast for the whole of an update or factory
  reset. Before, it went back to normal after 15 seconds.
- Screens no longer show internal names or codes.

### Languages

Every page is now translated: Setup, Node Status, Node software, Settings,
the update and reset pages, and the bar at the top of Router settings. The
languages are English, Español, Deutsch, Français, 中文 (简体), 日本語 and
Português (Brasil). Choose one in **Settings → Language**. Words you type to
confirm an action (`UPGRADE`, `RESET`, …) stay in English.

## Known issues

- From 25.0.32.0, node settings go back to the defaults once (above).
- Routers on 24.10.8.29.5.119 need a fresh install to reach 25.x (above).

---

## Testing

On a labelled BPI-R4, updated in place from 25.0.32.0 with this signed
release:

- Host test suite: all pass, including new regression tests for each fix
  above.
- Browser acceptance tests: setup (Quick and Guided), every page in all seven
  languages, node stop/start, reboot, factory reset, and updates keeping and
  resetting settings. All pass.
- 24-hour soak: 155 health checks, 11 reboots and 2 in-place updates, with no
  failures. The node stayed in sync throughout.
