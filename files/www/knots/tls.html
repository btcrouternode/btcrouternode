Please use a laptop or computer

The secure connection to this router is set up from a laptop or computer (Windows, Mac or Linux). Phones and tablets can’t do that easily.

Important — downloads: After you tap the orange button, look near the top of the browser (or the downloads arrow). If the browser asks to Allow, Save, or Keep the file (this is common in Firefox), you must click that — otherwise the file never finishes downloading.

Windows

  1. Click the orange Enable Secure Connection button.
  2. If your browser asks about the download, click Keep (Edge: click ⋯ next to the file, then Keep).
  3. Click the file install-bitcoin-node-trust.bat in the browser’s downloads list.
  4. Windows asks whether to run it — click Run. (A blue box “Windows protected your PC”? Click More info, then Run anyway.)
  5. Windows asks “Do you want to allow this app to make changes?” — click Yes.
  6. The secure Setup page opens by itself and the black window closes on its own.

macOS

  1. Click the orange Enable Secure Connection button.
  2. When the browser asks to open Script Editor, click Allow.
  3. In Script Editor click ▶ Run (top left).
  4. When your Mac asks for your password, type it and click Update Settings. The secure page opens by itself. Close Script Editor without saving.

Linux (Ubuntu, Debian, Mint)

  1. Click the orange Enable Secure Connection button.
  2. Click the downloaded file rnode-secure-connection.deb (Firefox: the downloads arrow, top right). App Center opens — click Install.
  3. Type your computer password and click Authenticate.
  4. Your browser reopens on the secure Setup page by itself (Firefox closes for a moment first). If it does not, close the browser and open it again.

Public certificates are not available for a home LAN IP. This local trust step is the supported path. A factory reflash creates a new CA — repeat once if HTTPS warns again.
