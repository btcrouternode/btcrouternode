Stop node

Stops bitcoind. The router stays on.

Start node

Starts bitcoind using the existing M.2 datadir. Available only when the node is stopped — stop first, then start. Optional ReIndex Node repairs the local chain database from blocks already on the M.2 — not a re-download.

Appliance power

Controls the whole appliance (router). Not the same as node start/stop above. Reboot and shutdown always stop the Bitcoin node first so chain data flushes cleanly. The same stop runs if you reboot from LuCI.

Reboot appliance

Restarts the router. LAN drops briefly.

Shutdown appliance

Powers the appliance off. You must power it on again manually.

Add another computer

On the new computer (Windows, Mac or Linux), open a browser and go to http://rnode.local — type it with http://. It shows Enable Secure Connection and the steps for that computer, then carries on to your router securely. After a factory reset or a renewed certificate, every computer does this once again.

Renew HTTPS certificate

Creates a new certificate for this router's secure pages. Every computer that installed the old one must install the new one again (Install trust page). Use this if a device that trusted this router was lost or sold.

Factory reset

Restores router settings to the appliance baseline (network, firewall, admin password) and starts first-run Setup again. Does not wipe the blockchain on the M.2 (N3 / S7). The Bitcoin node is stopped cleanly first.

You will be taken to a full reset page with progress, then first-run Setup.

Appliance upgrade

Upload a BPI-R4 sysupgrade image (*sysupgrade.itb — not the SD card *.img.gz). Paste the SHA256 from the release / checksum page (required — verifies the file before flash). Choose whether to keep router settings (default) or reset them to factory defaults. The blockchain on the M.2 is never wiped (NF9). Knots/Core binary updates remain on Node software.

Copy the hash from the same place you downloaded the image (e.g. the .sha256 file or website). You can paste a full sha256sum line — only the hash is used.
