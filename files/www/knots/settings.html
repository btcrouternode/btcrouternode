Stop node

Stops the Bitcoin node (bitcoind). The router stays on.

Start node

Starts the Bitcoin node (bitcoind) with the chain data already on the M.2 drive. Available only when the node is stopped — stop it first, then start it. The optional ReIndex Node repairs the local chain database from blocks already on the M.2 drive — it does not download the blockchain again.

Reindex in progress. Keep the power on — this uses blocks already on the M.2 drive and does not download the blockchain again.

Appliance power

Controls the whole appliance (the router) — not the same as starting or stopping the node above. Reboot and shutdown always stop the Bitcoin node first, so its chain data is saved cleanly. The same happens if you reboot from Router settings.

Reboot appliance

Restarts the router. The network drops for a short while.

Shutdown appliance

Turns the appliance off. You must turn it on again yourself.

Add another computer

On the new computer (Windows, Mac or Linux), open a browser and go to http://rnode.local — type it with http://. It shows Enable Secure Connection and the steps for that computer, then carries on to your router securely. After a factory reset or a renewed certificate, every computer does this once again.

Renew HTTPS certificate

Creates a new certificate for this router's secure pages. Every computer that installed the old one must add the router again (see Add another computer above). Use this if a device that trusted this router was lost or sold.

Factory reset

Restores router settings to the factory defaults (network, firewall, admin password) and starts first-time Setup again. The blockchain on the M.2 drive is not wiped. The Bitcoin node is stopped cleanly first.

You will be taken to a full reset page that shows the progress, then to first-time Setup.

Appliance upgrade

Upload a BPI-R4 sysupgrade image (*sysupgrade.itb — not the SD card image *.img.gz). Paste the SHA256 checksum from the release page (required — it checks the file before installing). Choose whether to keep your router settings (default) or reset them to factory defaults. The blockchain on the M.2 drive is never wiped. Bitcoin Core updates are on Node software.

Copy the hash from the same place you downloaded the image (for example the .sha256 file or the website). You can paste a full sha256sum line — only the hash is used.
