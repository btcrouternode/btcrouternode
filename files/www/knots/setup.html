Please use a laptop or computer

Setup starts by making the connection to your router secure, and phones and tablets can’t do that easily. Please do Setup from a laptop or computer:

  1. On the computer, join Wi‑Fi rnode with the password on the router’s sticker — or plug a cable into one of the router’s LAN ports.
  2. Setup opens by itself. If it does not, open a browser and go to http://192.168.1.254

After Setup, phones and tablets can use the new Wi‑Fi as normal.

Security

We are now going to make sure that your connection to your router is secure, which means it is safe. To start the process, click on the Enable Secure Connection button below. This will download a small file to this computer. Open the file and follow the prompts; this will enable the secure connection; you will need to provide the password to this device.

Detected device: …

Important Browser downloads: After you click the ‘Enable Secure Connection’ button, watch the top right of the browser (or the downloads arrow). The browser will ask to Allow, Save, or Keep the file being downloaded (this is common in Firefox). You Must click that option otherwise the file will NOT download. The file should save to your Downloads folder, not open as a page of text. You should be able to open the file from your browser.

On this computer (Ubuntu, Debian, Mint):
  1. Click the orange Enable Secure Connection button.
  2. Click the downloaded file rnode-secure-connection.deb (Firefox: the downloads arrow, top right). App Center opens — click Install.
  3. Type your computer password and click Authenticate.
  4. Your browser reopens on the secure Setup page by itself (Firefox closes for a moment first). If it does not, close the browser and open it again.

Wi‑Fi

Choose a new Wi‑Fi name and password that phones and laptops will use later.

  1. Network name is already filled as rnode — change it only if you want a different name.
  2. Type a Wi‑Fi password (at least 8 characters), then type it again to confirm.
  3. Country code is usually already set from your timezone — change only if wrong (e.g. AU, US, GB).
  4. Tap Save Wi‑Fi. Settings apply when you finish Setup — this computer stays on the factory network until then.

Default is rnode. You can change it.
