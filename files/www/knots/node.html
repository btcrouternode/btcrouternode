The image ships with Knots as the factory default. Your M.2 stores the last chosen implementation; that preference wins after every reboot (it is not a mismatch).

Switch implementation

Knots and Core share the same M.2 datadir. A normal switch restarts the node and does not wipe the chain. Wallet files on that disk are intended to be the same keys under either implementation.

Wallet detected on this appliance. Switching or replacing binaries is not recommended when a wallet is present. Keys are meant to stay on the shared disk, but if the wallet fails to load after a change you may need your offline backup / descriptor recovery material to regain access to funds. Prefer staying on the current software unless you have verified that backup.

Install or replace binaries

Upload an official *-aarch64-linux-gnu.tar.gz from bitcoinknots.org or bitcoincore.org. Files land on the M.2 under node-bin/. The previous install is kept for rollback. Chain data is never wiped.
