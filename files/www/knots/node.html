This router runs Bitcoin Core. Bitcoin Knots is no longer part of btcrouternode (since build 120): a router that ran Knots switched to Core by itself, keeping its chain data.

Install or replace Bitcoin Core

Upload an official Bitcoin Core *-aarch64-linux-gnu.tar.gz file from bitcoincore.org. It is stored on the M.2 drive under node-bin/. The previous version is kept so you can roll back. The blockchain data is never deleted.

Wallet detected on this appliance. Replacing the node software is not recommended when a wallet is present. The keys are meant to stay on the shared drive, but if the wallet fails to load after a change you may need your offline backup (or descriptor recovery material) to regain access to your funds.
