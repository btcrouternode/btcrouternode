This router runs Bitcoin Core. Bitcoin Knots is no longer part of btcrouternode (since build 120): a router that ran Knots switched to Core by itself, keeping its chain data.

Install or replace Bitcoin Core

Upload an official Bitcoin Core *-aarch64-linux-gnu.tar.gz from bitcoincore.org. Files land on the M.2 under node-bin/. The previous install is kept for rollback. Chain data is never wiped.

Wallet detected on this appliance. Replacing binaries is not recommended when a wallet is present. Keys are meant to stay on the shared disk, but if the wallet fails to load after a change you may need your offline backup / descriptor recovery material to regain access to funds.
